# Локальная генерация аудио

VN Studio использует ACE-Step 1.5 для создания фоновой музыки и музыкальных акцентов по текстовому описанию.

## Как это устроено

1. В панели AI-модели нажми «Установить движок». Сервер скачает исходники ACE-Step и установит отдельное Python 3.11-окружение через uv.
2. Нажми «Скачать и загрузить модель». ACE-Step запускается напрямую модулем `python -m acestep.api_server` из своего виртуального окружения (без зависимости от сгенерированного файла `acestep-api.exe` на Windows) и автоматически загружает модель acestep-v15-turbo с Hugging Face или ModelScope.
3. В музыкальной ноде выбери режим «Музыка» или «Эффект» и нажми «Создать с помощью AI».
4. Прослушай результат и добавь его в ассеты проекта. Трек автоматически назначится выбранной ноде.

Аудиосервис слушает только 127.0.0.1:8766; фронтенд обращается к нему через основной AI-сервер. Для генерации с другого компьютера достаточно использовать сетевой адрес AI-сервера в настройках VN Studio.

## Изоляция зависимостей

ACE-Step использует собственные версии PyTorch и Transformers. Чтобы они не заменяли зависимости основного AI-сервера, его исходники и виртуальное окружение размещаются в ai-server/audio-runtime/ACE-Step-1.5. Сгенерированные файлы сохраняются в ai-server/audio-runtime/generated.

Основному AI-серверу требуется пакет uv из ai-server/requirements.txt. Если uv отсутствует в активном окружении, установщик автоматически поставит его через pip, используя тот же Python, которым запущен AI-сервер. Для создания окружения используется Python 3.11, который uv при необходимости может установить самостоятельно.

Перед каждым запуском API выполняется инкрементальная сверка окружения командой `uv sync --locked`. Это восстанавливает отсутствующие библиотеки в ранее созданном `.venv`, не скачивая повторно исходники ACE-Step.

## Оборудование и ограничения

ACE-Step подбирает профиль запуска под обнаруженное устройство. В документации проекта указаны CUDA, Apple MPS, AMD ROCm, Intel XPU и CPU. Для режима DiT-only официальная таблица указывает от 4 ГБ VRAM; для систем с малым объёмом видеопамяти рекомендуется отключать дополнительную языковую модель. Скорость на CPU может быть значительно ниже.

ACE-Step ориентирован на музыку и музыкальные фрагменты. Минимальная длительность генерации — 10 секунд. Поэтому для коротких кликов, тональных сигналов и простых звуковых уведомлений сохранён существующий синтезатор звуков VN Studio. Режим «Эффект» использует сгенерированную композицию как однократный аудиофрагмент, а режим «Музыка» — как зацикленный трек.

Подробности и обновления движка: https://github.com/ACE-Step/ACE-Step-1.5

Встроенный загрузчик использует зафиксированную ревизию исходников ACE-Step: ca1e85fe9430179831e6bc6be790c332190a3866. Для автоматической загрузки весов нужен доступ к Hugging Face или ModelScope.
